# Michael Jay Juan | Marketing Operations Portfolio

This repository contains the source code for my custom-built, dark-mode professional portfolio. 

### 🛠️ Tech Stack & Architecture
- **Frontend:** Semantic HTML5, Vanilla CSS (Dark Mode Optimized)
- **Marketing Stack Integration:** GoHighLevel (GHL) CRM, Webhooks, and Automated Lead Capture
- **Design Ops:** Adobe Creative Cloud & Canva for digital asset creation

### 🚀 Purpose
As a Marketing Operations Architect, I believe marketing shouldn't just be creative—it must be structurally sound. I hand-coded this portfolio to demonstrate that I bridge the gap between creative design (front-end UI) and technical systems (backend CRM pipelines).
